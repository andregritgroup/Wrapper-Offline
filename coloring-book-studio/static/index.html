With Runware (AI settings), press Make reference picture for each character, or upload your own drawing of them. Every page they appear on copies that picture, so they look the same throughout the book. Also describe each character the same way every time: animal or person, age, body shape, hair, clothes, one or two stand-out features. This exact description is added to every picture they appear in, which is what keeps them looking alike from page to page. Add other names the story uses for them (e.g. “Gran, Ouma”) so they're recognised.
